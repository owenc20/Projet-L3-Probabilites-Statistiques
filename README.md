# Projet de probabilités et statistiques — L3 Mathématiques

Projet réalisé dans le cadre de ma troisième année de Licence de Mathématiques à l'Université Paris-Saclay.

Ce projet porte sur l'étude du processus du restaurant chinois, un modèle probabiliste permettant de générer des partitions aléatoires. L'objectif est d'étudier ses propriétés théoriques et asymptotiques, tout en illustrant le modèle à l'aide de simulations numériques.
